# 🏕️ 2026 優異旅團獎勵計劃 — 評分系統（v4）

港島地域 · 一張 Google Sheet + 一個 Apps Script 專案 + Vercel 前端。
**無電郵**；旅團網上填表送出（後端記時間＋內容）；區／地域帳號登入審核。

## 角色與流程
- **旅團**（免登入）：揀區→揀旅團→揀支部→填評分表（即時計分）→**確認送出**（後端記錄時間＋內容）。**唔會見到合格線。**
- **審核員**（每區 1 個帳號）：睇本區已遞交 → **批核**。
- **區總監**（每區 1 個帳號）：睇本區全部 → 可**跳過審核員直接審批** → **確認送交地域**；可刪除。
- **地域秘書處**（1 個帳號）：一次過睇**各區獨立總覽＋統計**、**設定合格分數線**、匯出全部。
- 預設 **15 個帳號**（7 區 × 審核員＋區總監 ＋ 地域）。

## 合格分數線
- 存喺試算表 **`Config`** 工作表 `passMark`（地域登入後可改，預設 80）。
- **旅團睇唔到**；審核員／區總監／地域都睇到（總分 ≥ 線 = 合格）。

## 檔案
```
index.html              Vercel 前端（GAS／fetch雲端／MOCK 自動適應＋支部顏色）
apps-script/Code.gs     GAS 後端（15帳號＋審批流程＋合格線＋統計＋匯出）
apps-script/app.html    GAS 前端檔
data/config.json        填 GAS 後端 URL（留空＝MOCK 示範）
data/groups.json        201 個旅團參考資料
docs/                   旅團／審核員·區總監／地域／MOCK 教學
原始官方表格-5個分支/   官方 Excel 評分表（參考）
vercel.json  README.md  DEPLOY.md
```
