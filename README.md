# 🏕️ 2026 優異旅團獎勵計劃 — 評分系統（v5）

港島地域 · 一張 Google Sheet + 一個 Apps Script 專案 + Vercel 前端。
5 個彩色支部分頁；右上角登入（區／地域／超管）；全前端帳號管理；各支部獨立合格線；獨立打印。

## 主頁
- 一入 APP = **5 個支部分頁**（小童軍🟠／幼童軍🟡／童軍🟢／深資🔴／樂行🔵）。旅團揀支部→區→旅團→填表→確認送出。
- 右上角「🔐 登入」＝區／地域／超管。

## 帳號（setup 預設）
- **地域**：`HKIR`（密碼 `1234`）
- **各區審核員**：`CHW SKW HKN WCH VIC HKW HKS`（= 柴灣/筲箕灣/港島北/灣仔/維多利亞城/港島西/港島南；密碼 `1234`）
- **各區總監**：上述 + `DC`（如 `SKWDC`；密碼 `1234`）
- 另有**隱藏超管**（不顯示於任何清單／MD／記錄），權限最高。
- 所有帳號可自行改密碼；上級可改／刪下屬；DC 可加同區帳號，HKIR 可加地域帳號（全前端）。

## 流程
旅團送出（已遞交）→ 審核員／區總監批核（已審核）→ 區總監確認（已確認＝送交地域）→ 地域總覽。區總監可跳過審核員直接確認。

## 合格線
- **各支部獨立**合格線（地域登入設定，預設各 80）。**旅團睇唔到**；區／地域睇到。

## 打印
- 任何旅團表單可獨立列印（檢視→🖨️ 列印，Excel 格式）。
- 各區／全區統計可獨立列印。

## 檔案
```
index.html / apps-script/app.html   前端（5 分頁＋三模式＋支部彩色）
apps-script/Code.gs                  後端＋前端（前端以 base64 包入，**單檔部署，唔使另建 app.html**）
data/config.json                     填 GAS URL（留空＝MOCK）
data/groups.json                     201 旅團
docs/                                教學
```

雙擊 `index.html`（MOCK，密碼 `1234`；超管 `超管/0728`）：地域 `HKIR`、區 `SKW`/`SKWDC`。
