# 🏕️ 優異旅團獎勵計劃 — 評分系統（支援年份及評選期動態設定）

港島地域（HKIR）· **一個 Apps Script 檔（Code.gs）搞掂**：前端＋後端＋試算表，全部喺同一個 GAS 入面。

## 點運作
- `Code.gs` 一個檔，前端正以 **base64 包埋**喺入面，`doGet` 解碼還原成網頁（GAS 部署專用）。
- 前端透過 **`google.script.run`**（在 GAS 沙盒內）或 **`fetch POST`**（在 GitHub Pages／Vercel 外部網址）直接寫入後端。
- **首次開網址自動初始化**：自動建立試算表 + 帳號 + 合格線。**唔使手動 run setup()。**
- `index.html` 為**完整單頁應用（SPA）前端**，打開 GitHub Pages / Vercel 網址**不再突登轉向跳走**，保留自訂靚網址，並直接以 fetch 通訊連接後端。

## 帳號（自動建立，密碼預設 `1234`）
- **地域**：`HKIR`
- **各區審核員**：`CHW SKW HKN WCH VIC HKW HKS`（柴灣／筲箕灣／港島北／灣仔／維多利亞城／港島西／港島南）
- **各區總監**：上述 + `DC`（例如 `SKWDC`）
- **隱藏超管**（不顯示於任何清單／記錄），權限最高。
- 審核員／區總監／地域可自行改密碼（登入後按「🔑 改密碼」，需驗證舊密碼）；隱藏超管密碼寫死喺 Code.gs（`_S`），唔落後端、唔支援改密碼。上級可改／刪下屬；DC 可加同區帳號，HKIR 可加地域帳號（全前端）。

## 評分流程
旅團送出（已遞交）→ 審核員批核（已審核，**須填評審員姓名＋職位**）→ 區總監確認（已確認）→ 地域總覽。
**區總監唔可以跳過審核員**直接確認。

### 🕒 自動時間記錄（v46 起，全程毋須手填日期）
- 評審員／區總監查看表格後按「批核／確認」即完成簽署，**完全毋須填日期**；遞交、評審、確認三個時間由**後端自動記錄**。
- **評審員**檢查表格時：看到遞表人**何時遞交**。
- **區總監**檢查表格時：看到遞表人**何時遞交**＋評審員**何時評審**。
- **地域（HKIR／超管）**：看到**全部 3 個時間及進度**（●○○→●●○→●●●），總覽表及列印報表均顯示。
- **評審員及區總監可修改分數**：表格內任何評分欄位均可改，改完按「💾 儲存修改」或在「批核／確認」時一併儲存。

## 系統年份及評選期（地域登入設定，來年或將來可持續使用）
為方便來年（例如 2027、2028 或以後）繼續使用而毋需改動程式碼，**地域管理員／隱藏超管**登入「地域總覽」後，可直接修改：
- **獎勵計劃年份**（預設 2026，可改為 2027、2028 等）
- **評選年度**（預設 2025，可改為 2026 等）
- **評選期開始日期**（如 `2025-01-01`）
- **評選期結束日期**（如 `2025-12-31`）
儲存後，全站標題、各支部評分表標頭、最低標準財務報告年度、下載 Excel 檔案名稱及報表時間範圍將自動套用新設定！

## 合格線
各支部**獨立**合格線（地域登入設定，預設各 80）。**旅團睇唔到**；區／地域睇到。
